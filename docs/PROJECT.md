# Project record

## Objective

JDBC shard router that routes statements by shard key with jump consistent hashing and merges scatter-gather results for ORDER BY, LIMIT, GROUP BY and aggregates

## Scope

- In scope: the public API documented in [README.md](../README.md), documented and tested.
- Out of scope: anything that needs dependencies or I/O without an accepted ADR.
